# Demo Guide

## 1. Start the platform

```bash
docker compose up --build -d
```

## 2. Open the services

- Streamlit dashboard: `http://localhost:8501`
- FastAPI Swagger UI: `http://localhost:8000/docs`
- n8n: `http://localhost:5678`

## 3. Demonstrate the workflow

1. Trigger or observe threat-intelligence ingestion.
2. Show normalized vulnerability data.
3. Display risk and prioritization results.
4. Demonstrate the dashboard views.
5. Explain AI-assisted analysis and remediation playbooks.

## 4. Testing note

Use non-production credentials and test data during demonstrations.
